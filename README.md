# LibraSPHERE - Smart Academic Library Portal

LibraSPHERE is a full-stack PHP/MySQL library management system that connects physical book circulation with a verified academic resource hub for notes and previous year question papers.

The project is built around two real user roles, Admin and Student, with protected portals, session-based authentication, book issue/return tracking, digital resource approval, smart search, recommendations, and operational analytics.

## Live Demo

https://lms-easy.infinityfreeapp.com/



## Standout Features

- Role-based Admin and Student portals with separate permission sets
- Read-only public demo mode for safe reviewer access
- Book catalogue management for 40+ titles and 280+ copy records
- Complete borrowing lifecycle: issue, return, due-date tracking, and overdue visibility
- Smart Search across books, approved notes, and PYQs
- Student recommendations based on course and borrowing history
- Admin analytics for most issued books, category coverage, overdue books, and resource pipeline
- Notes and PYQ upload workflow with admin approval
- Normalized MySQL schema covering books, students, issued books, returned books, notes, and PYQs
- Responsive Bootstrap interface with dark/light mode

## Tech Stack

- Frontend: HTML5, CSS3, JavaScript, Bootstrap 5
- Backend: PHP, server-side validation, PHP sessions
- Database: MySQL, relational schema design, CRUD operations
- Tools: XAMPP, phpMyAdmin, VS Code
- Deployment: InfinityFree

## What Makes It Different

Most beginner library systems stop at book CRUD. LibraSPHERE adds a practical academic layer:

- Students can discover learning resources, not only view books.
- Admins can review academic uploads before publishing them.
- The dashboard includes analytics that help understand resource demand.
- Public demo access is intentionally read-only for safe evaluation.
